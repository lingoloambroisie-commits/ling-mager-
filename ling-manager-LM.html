Mon équipe — adresses e-mail autorisées

Ajoutez l’adresse e-mail de chaque collaborateur. Il crée son compte avec cette adresse (« Créer un compte ») et accède automatiquement aux mêmes données que vous, sans scanner de QR Code. Si le serveur principal désactive votre sous-serveur, vous et toute votre équipe ne pouvez plus rien enregistrer jusqu’à la réactivation.

Interconnexion des appareils — synchronisation QR

Appareil principal (A) : appuyez sur « Créer un espace et son QR Code ». Autres appareils (B, C…) : connectez-vous avec le même compte e-mail, puis « Scanner le QR Code » (ou saisissez le code). Tous les appareils voient alors les mêmes informations, mises à jour automatiquement dès qu’Internet est disponible. Les données déjà présentes sur chaque appareil sont conservées et fusionnées.

Synchronisation non activée — les données restent sur cet appareil.
Connexion d’un autre appareil

Sur l’appareil B, ouvrez Ling-Manager, créez son mot de passe local, connectez-vous au même compte e-mail, puis scannez ce QR Code depuis Paramètres. La synchronisation démarre dès que les deux appareils sont en ligne.

Important : ne partagez le QR Code / code d’espace qu’avec les appareils autorisés. Toute personne qui possède ce code peut lire et modifier les données de l’espace.

Paramètres de sauvegarde

La sauvegarde contient les opérations financières, les agents, les salaires, les réclamations et les prêts. Gardez-la dans un endroit sûr.

Attention : la réinitialisation est définitive. Si la synchronisation est active, elle efface aussi les données de tous les appareils connectés. Téléchargez une sauvegarde avant.

À propos

Ling-Manager — application de gestion financière : recettes, dépenses, salaires des agents, réclamations et prêts, avec synchronisation multi-appareils.

Le serveur principal contrôle l’accès des sous-serveurs. Chaque sous-serveur gère son équipe, ses agents et ses activités.
